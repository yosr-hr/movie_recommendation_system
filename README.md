# movie_recommendation_system

## 📌 Project Overview

This project aims to develop a Movie Recommendation System using classical Machine Learning techniques

The system recommends movies based on movie characteristics and user preferences

## 🎯 Objectives

- Explore and analyze movie datasets
- Apply data preprocessing and feature engineering
- Implement recommendation algorithms
- Compare different recommendation approaches
- Evaluate recommendation performance

## 🛠️ Technologies

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Google Colab
- GitHub
